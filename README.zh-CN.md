# AgentTrail

[English](README.md) | [简体中文](README.zh-CN.md)

在 VS Code 中审查编程智能体的文件变更、观察终端活动。
可配合 Codex、Claude 等工具使用，不调用 AI API。
审查界面跟随 VS Code 显示语言：中文环境显示中文，其他语言统一显示英文。

## 开始使用

1. 打开工作区，扩展会自动捕获审查基线。
2. 让智能体修改文件，然后在资源管理器中打开 **智能体变更**。
3. 对比并**接受**或**拒绝**单处变更、整个文件或全部待审查变更。接受会保留代码，拒绝会恢复基线。
4. 打开 **会话时间线**，查看文件活动和终端命令，包括工作目录、耗时和退出码。

**历史记录**保留已审查的变更供参考。**开始会话**／**重置会话**会开始新一轮审查，旧时间线仍可查看。**结束会话**停止记录，但仍可继续审查已有变更。

安装 Codex 扩展后，可用**请求修改**将选中的变更发送给 Codex，也可通过选区悬浮菜单将代码、文件或文件夹加入对话。

## 环境与限制

- 需要 VS Code **1.85+**；终端活动需要 **1.93+**，并启用终端的 **Shell Integration**。
- 支持审查已有 UTF-8 文本文件。新增、删除文件仅作为历史记录，二进制文件不在范围内。
- 在 VS Code 中手动编辑会更新该文件的基线；切换 Git 分支会开始新一轮审查。编辑器的撤销操作无法撤销接受变更。
- 活动记录不判断变更或命令来自谁，暂不采集终端输出。重载窗口后，历史记录和时间线会清空。
- 不修改真实 Git 索引或暂存区。

## 开发

```sh
npm install
npm run compile
npm run test:unit
npm run test:integration
```

按 **F5** 启动扩展开发宿主。集成测试默认使用 VS Code 1.85.2；设置 `VSCODE_EXECUTABLE_PATH` 可测试其他已安装版本。
